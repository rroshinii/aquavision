Create your dataset in this folder structure:

<dataset-root>/
  images/
    train/
      image1.jpg
      image2.jpg
    val/
      image3.jpg
      image4.jpg
  labels/
    train/
      image1.txt
      image2.txt
    val/
      image3.txt
      image4.txt
  data.yaml

Label format (YOLO):
<class_id> <x_center> <y_center> <width> <height>

Example:
0 0.512 0.450 0.180 0.260

Class mapping:
0 = diver
